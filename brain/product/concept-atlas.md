# Concept Atlas (product notes)

Non-generic course visualization — see PRD P6 and
`.claude/skills/concept-atlas/`. Key product commitments:

- Units render as bounded regions, not a flat force-directed hairball.
- Layout follows conceptual dependency, not lecture chronology.
- Mastery is shown via discrete state + ring + color (redundant encoding,
  not color alone).
- Weak edges (relationships) are first-class learner-state indicators, not
  just weak nodes.
- Concept clicks open a stable detail panel — the graph doesn't rearrange
  itself under the user.
- Progressive disclosure (collapsed/expanded units) prevents hairballs as
  course size grows.
- The user's mental map (approximate layout) should be preserved across
  graph revisions where possible.
